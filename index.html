Gemma in the built-in engine
Runs on this computer with its matching projector. Enables microphone Listen & Reflect, images, document tools and exact text token counts.

          
Another local GGUF
Uses the same engine controls. Images need a compatible model and projector; document tools need function calling. Text counts use the local tokenizer. Listen & Reflect needs Gemma 4 12B.

          
LM Studio, Ollama & cloud
Chat, images and document tools depend on the selected model and server. Text counts are estimates, even for Gemma in LM Studio. Cloud connections send submitted material to the provider.
